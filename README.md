# Portfolio

## Overview
A personal portfolio website built to showcase selected projects and provide a single, professional online presence.
This project exists to practice structuring a real-world frontend application and presenting work clearly using modern tooling.

## Demo
- []Live URL](https://mukulkashyap.com)

## Features
- Responsive layout optimized for desktop and mobile
- Dedicated sections for projects, skills, and contact information
- Smooth animations and transitions for improved user experience
- Clear project presentation with links to source code and demos

## Tech Stack
- Framer
- JavaScript
- HTML
- CSS

## What I Learned
- Designing and structuring a portfolio for clarity and scannability
- Using Framer to build and deploy a production-ready frontend
- Balancing visual design with performance and usability
- Presenting projects with concise, value-focused descriptions
